В ходе проведенного исследования было выявлено, что для нашей задачи лучше подходит метод матричной факторизации SVD. Результаты метрик выбранного подхода оказались лучше, чем у Item-based Collaborative Filtering.

В процессе работы были реализованы различные подходы к расчету метрик:

1. Метрики считаются на основе 1 релевантного фильма и 99 негативных для каждого пользователя. Данная метрика показывает, насколько хорошо модель может справляться с новыми пользователями, и оценивает устойчивость модели к несбалансированному входу с большим количеством негативных данных.

2. Метрики считаются на основе выборки, состоящей из всех релевантных фильмов и негативных примеров в количестве, равном 99*количество релевантных фильмов. Данная метрика так же, как и предыдущая показывает насколько хорошо модель справляется с новыми данными, но отличается тем, что основывается на конкретных пользователях.

3. Метрики считаются только для известных значений на тестовой выборке. Данный вариант оценивает то, насколько хорошо модель справляется с пользователями, которых она уже видела.

Мы выбрали 3-ий вариант метрик для оценки наших моделей. Мы считаем его наиболее подходящим, так как наши модели не умеют работать с холодными пользователями. Также наши модели не поддерживают дообучение, то есть для добавления новых данных требуется полностью переобучать модель с нуля.
