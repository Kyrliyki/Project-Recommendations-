# Project-Recommendations-

## Модель Матричной Факторизации (SVD):
### Инструкция по эксплуатации.
1. Проверить установлен ли phyton версии 3.12 если нет установить с официального сайта
2. Проверить установлена ли poetry если нет прописать в консоль **`pip install poetry`**
3. Установить зависимости для запуска скрипта через команду **`poetry install`**
4. После чего для запуска модели использовать команду **`poetry run run_svd_pipeline`**
