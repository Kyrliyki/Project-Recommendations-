## Модель Матричной Факторизации (SVD):
#Инструкция по эксплуатации.
1. Проверить установлен ли phyton версии 3.12 если нет установить с официального сайта
2. Для того чтобы запустить модель на вашем PC необходимы следящие библиотеки:
   - pandas (>=2.3.3,<3.0.0)
   - numpy (=1.26.4)
   - surprise (>=0.1,<0.2)  
   - scikit-learn (>=1.7.2,<2.0.0)
   - dask (>=2025.10.0,<2026.0.0)
   - dask-ml (>=2025.1.0,<2026.0.0)
   - pydantic (>=2.12.2,<3.0.0)
   - logging (>=0.4.9.6,<0.5.0.0)
   - requests (>=2.32.5,<3.0.0)
   - tqdm (>=4.67.1,<5.0.0)
3. Скачать файлы проекта в удобную для вас папку.
4. После чего запустить файл matrix_factorization_based_cf.py который расположен по пути: Project-Recommendations-\src\pipelines\matrix_factorization_based_cf.py
